# Case Lab — интерфейсы и CMS

Навигация по двум реализациям: приложению задач на JavaScript и контентному сайту на 1С-Битрикс.

| Проект                                                               | Возможности                                                         | Что показывает                                                     |
| -------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------ |
| [Список задач](https://github.com/DenisChernykh/todo)                | Добавление, завершение, удаление, групповые действия и localStorage | DOM, события и согласованность интерфейса с сохранённым состоянием |
| [Сайт на 1С-Битрикс](https://github.com/DenisChernykh/CaseLabSlider) | PHP-шаблоны, меню, контентные секции и компонент голосования        | Расширение CMS и интеграция пользовательских форм                  |

Исходники и инструкции находятся в соответствующих репозиториях. Вместе проекты показывают работу как с JavaScript-интерфейсом, так и с серверными шаблонами CMS.
