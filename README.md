# Case Lab — шаблон контентного сайта на 1С-Битрикс

PHP-шаблон сайта с новостями, статьями, меню и формой согласия на обработку данных. Репозиторий содержит сам шаблон и адаптации стандартных компонентов Битрикс.

## Возможности

- Общая шапка и подвал, навигация и оформление контентных страниц.
- Списки и подробные страницы новостей и публикаций.
- Переопределённые шаблоны компонентов `news`, `news.list`, `news.detail` и `menu`.
- Компонент пользовательского согласия и вложенный интерфейс голосования.
- JavaScript для форм, масок ввода и просмотра изображений.

## Что показывает проект

Работу с существующей CMS: PHP-шаблонами, параметрами компонентов, результатами выборок и клиентскими ресурсами. Код раскрывает адаптацию стандартных механизмов 1С-Битрикс под интерфейс сайта и переиспользование общих частей. Это релевантно CMS-разработке, PHP-вёрстке и поддержке контентных проектов.

## Установка

Разместите каталог `main` в `local/templates/main` установленного 1С-Битрикс и выберите шаблон в настройках сайта. Настройте инфоблоки, меню и параметры компонентов под структуру контента. Ядро Битрикс устанавливается отдельно.

Проект использует PHP-шаблоны с короткими открывающими тегами; для окружения включите `short_open_tag`. Отдельная Node.js-сборка не требуется.
